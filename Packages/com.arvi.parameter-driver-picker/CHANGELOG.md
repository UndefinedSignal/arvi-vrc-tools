# Changelog

## 1.1.1
- Исправлено: консоль засыпало ошибками «… uses parameter … which does not exist» от других контроллеров. Контроллер драйвера теперь ищется один раз и сначала в окне Animator, а инспектор SDK создаётся только когда включён.

## 1.1.0
- Поиск теперь прямо в полях Destination и Source, а не отдельным блоком сверху: нативный попап SDK больше не используется.
- Все записи драйвера видны сразу, у каждой кнопки ↑ ↓ × (перемещение и удаление).
- Кнопка «Стандартный инспектор SDK» внизу — переключиться обратно на инспектор VRChat (запоминается).
- При выделении нескольких драйверов показывается инспектор SDK.

## 1.0.0
- Первый релиз.
- Блок «Параметры (поиск)» над инспектором VRC Avatar Parameter Driver: Destination для Set / Add / Random, Source и Destination для Copy.
